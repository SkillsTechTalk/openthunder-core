# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for a security problem.

Scope: the evaluator, importers, receipt signing and verification, the CLI, the GitHub Action, and the VS Code
extension in this repository. A signature proves who produced a receipt and that it was not changed; it does not
prove a test was meaningful. Reports about that boundary are welcome too.
